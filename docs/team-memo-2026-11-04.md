## 3. Sam's decisions (final)
A. Engines are identical. Every VKOLE engine works the same way on the app and the website: same questions, same leveling, same timing, same feedback, same wording. Engines improve over time, always on both sides together.

B. Student information is separate. The app and the website do not share student information: no levels, progress, answers, seen questions, day clock, session reports, names, ages, or grades.

C. Only account information is shared: creating the parent account and signing in; paid access and the free week (so no family ever pays twice); which student places are in use (see D).

D. Two students total per account, across the app and the website together. Each account has two places: Student 1 and Student 2. There is no third. When a parent adds a child on either side, the parent picks Student 1 or Student 2. The parent picks the same place for the same child on both sides. Only the place number is shared. The child's name and progress stay on each side separately. Parent-facing wording, both sides: "Pick the same place for the same child on the app and the website."

E. One email sender. Every parent email from the app and the website comes from kirksam.alpha@dotheimpossible.ai. This is the official address.

F. Report emails. Each side sends its own session reports. The app no longer posts its reports to the website. No relay, not even as a stopgap.

G. No existing students. No one uses either side yet. Nothing to move. Clear all test accounts with the admin button before release.

H. Alphabet, not spelling. The engine is VKOLE/Alphabet on both sides. A separate Spelling engine comes later. No page, email, PDF, or price card may promise spelling.

I. Library wording. The number of engines will grow. Stop saying "eight."
- "Eight climbs" becomes "A library of climbs"
- "Eight engines, one child" becomes "A library of learning engines, one child"
- "all eight engines" becomes "the whole library of learning engines"
- "All eight engines: mathematics, ..." becomes "The whole library of learning engines. Today it holds mathematics, ..."
Do not change: "eight-question assignment", "eight items", the word "eight" in sight-word lists, URLs, route names, file names, code names, spaceXsiText(), or system prompts.

## 4. Engine rules that must match on both sides
Sight Words, each word: show the word. The child has 20 seconds to read it aloud. Read correctly: sparkle, wait 2 seconds, next word. One misread, or 20 seconds with no answer: say the word aloud once, wait 2 seconds, next word. No second try.

Sight Words, moving to a harder list: one pass is every word in the current list shown once. At the end of a pass, 70 percent or more read correctly on the first try opens the next harder list. Under 70 percent, the same list repeats. A 20-second timeout counts as a miss. The child never moves to an easier list. The last list repeats. Keep the 70 in one named setting on each side (SIGHT_WORD_PASS_PERCENT = 70). Both sides always use the same number. Today the app moves to the next list after every pass. This must change on both sides. Website first, then the app.

## 6. Rules
An engine change is finished only when it works the same on both sides. New engines start in the app. Changes to existing engines start on the website, then the app. Never add a new way for student information to move between sides. Nothing is sent to Apple or Google without Sam's OK. If you find a problem, report it. Do not quietly work around it. Plain words. Parent-facing text at about a 6th-grade reading level. Automated tests never send real emails.
